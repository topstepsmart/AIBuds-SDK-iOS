# AIBuds Live Stream Flutter

Flutter plugin for AIBuds live stream playback and RTSP-to-RTMP streaming.

- [简体中文](docs/zh-Hans.md)

## Quick Start

```yaml
dependencies:
  aibuds_live_stream_flutter:
    path: path/to/aibuds-live-stream-flutter
```

```dart
import 'package:aibuds_live_stream_flutter/aibuds_live_stream_flutter.dart';
```

The plugin currently targets iOS. Use a physical iOS device when validating live RTSP playback or RTMP push streaming.
